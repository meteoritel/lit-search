# 文献检索质量优化实施计划（已归档）

状态：实施与评测已完成，2026-11-09 归档。交付版本为 0.5.0；阶段 E 按收益门槛完成实验，保留固定抓取分配。

## 目标与约束

在明确的候选与补齐预算内，提高专题召回和前列精度，保存可追溯的检索与排序证据。保留标准库运行时、`../../../src/litsearch.py` 单文件，以及 `SearchClient.search(QueryPlan) -> SearchResult` 完整检索 Interface。

起点为[南海原生生物时间序列测试](../../../.local/archive/2026-11-09-retrieval/test-report.md)：候选缺失摘要造成硬过滤漏检，跨查询原始分值缺少统一尺度，来源查询与候选窗口影响核心覆盖。

## 阶段与结果

| 阶段 | 实施内容 | 验收结果 |
|---|---|---|
| A：协议与评测 | Crossref 全页明确 score 降序；空 require 联网前拒绝；评测标签按 DOI/来源身份互斥，gold 外记未判读 | SearchClient 离线分页与校验回归通过；受控 cursor 请求返回 score 与已知核心文献 |
| B：摘要补齐 | 合并后、硬过滤前按 DOI 查询 Europe PMC core；只补空摘要，记录来源、预算与正负缓存 | 真实元数据回放的核心保留由 4/17 恢复到 7/17；预算、缓存、错误响应和整体网络失败契约通过回归 |
| C：证据与排序 | 保存 source/query/global rank；同列表最佳名次；可选 RRF、字段加权 BM25、hybrid；字段过滤与排序解释 | 同池排序与摘要消融可离线复现；默认仍为 citations |
| D：查询与来源 | concepts 按来源编译宽/精查询；Europe PMC 完整 Provider；可审阅的 TOML 预设 | 两源候选命中原 gold 的 10/17 核心、24/40 核心加相关；独立钙钛矿主题回放完成 |
| E：抓取分配 | 固定候选流上比较轮流取页与按新增身份比例取页 | 较大预算下新身份策略的相关召回较低；未达到上线门槛，生产保留固定分配 |

## 数据流与交付

QueryPlan → 来源查询编译与 cursor 抓取 → 命中证据与身份合并 → 按需补空摘要 → 显式过滤 → 可选证据排序 → 截断与 SearchResult。网络访问复用 Http Seam，CLI 负责终端与文件输出。

## 评测边界

南海主题仍是主要排序评测集；原 gold 来自 Europe PMC。钙钛矿样本的候选全部直接相关，缺少难负例。新增候选使用标题/摘要判读，尚无独立人员盲审。保守 DOI 合并保留的无 DOI 同标题条目需人工核对。

默认排序的调整、来源权重与向量精排留待含难负例的多主题独立评测。它们不属于当前生产行为。
