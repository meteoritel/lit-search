# Domain docs

本仓库采用 single-context。领域术语与接口以 [Python 契约](../python.md)和 [CLI 规则](../usage.md)为准。

## 阅读规则

探索代码库前，读取已有的 `GLOSSARY.md`，并读取 `docs/adr/` 中与当前任务相关的 ADR。

当前未设置术语表和 ADR。需要独立记录时，根目录 `GLOSSARY.md` 保存已确认术语，`docs/adr/` 保存已确定的架构决策；由 `domain-modeling` 按需创建。

## 术语与决策

Issue 标题、设计建议、假设与测试名称使用项目契约中的领域词汇。遇到新概念时，先核对代码与文档中的现有用语，再确定名称。

建议与现有 ADR 冲突时，明确指出对应 ADR 与重新讨论的理由。
